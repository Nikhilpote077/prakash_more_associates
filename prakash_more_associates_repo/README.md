# Prakash More & Associates - Architecture & Interior Design Website (Phase 1)

## Overview

This is Phase 1 of the website for **Prakash More & Associates**, an Architecture and Interior Design studio based in Mapusa, North Goa.

The design embodies luxury, architectural precision, and coastal elegance using modern dark theme tokens, refined typography (Cormorant Garamond + Plus Jakarta Sans), grid alignments, and clean mobile responsiveness.
